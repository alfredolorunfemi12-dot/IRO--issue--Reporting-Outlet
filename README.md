## 1. Project Description
IRO is a web-based platform designed to allow students of Adekunle Ajasin University and residents of host communities: Akungba, Iwaro, Etioro, and Ayegunle to easily report community issues such as Security, Electricity, Water, and Road problems.

The goal is to provide a centralized, traceable, and fast channel for reporting and resolving issues, replacing slow WhatsApp complaints and physical reports.

## 2. Key Features
- **Report Submission**: Users can submit issues with community, type, description, and photo
- **Issue Tracking**: Each report gets a unique ID for tracking
- **Admin Dashboard**: Admins can view, filter, and update issue status
- **Mobile Friendly**: Simple UI that works on low internet
